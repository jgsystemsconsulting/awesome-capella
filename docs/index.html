Awesome Capella

Curated Capella tool and Arcadia method resources for MBSE practitioners. Version 0.1.0.

This is a public-domain (CC0) curated index of Eclipse Capella, the Arcadia method, addons, scripting libraries, training, and related community material. Nothing to install: open the list and follow the links.

First run

  1. Open the full list on GitHub (README with searchable Contents).
  2. Jump to a section that matches your work (method, tool, scripting, training).
  3. Suggest a resource or report a dead link via the repository issue forms.
